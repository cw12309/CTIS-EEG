# CTIS-EEG 认知训练与干预系统 (Web 版)

一个面向早期阿尔茨海默病（AD）患者的居家认知训练 Web 系统，包含 5 大训练任务、设备连接、数据记录与统计。

## ✨ 特性

- 🎨 **温馨米色风格** — 浅米底 + 棕橘主色，长时间观看不刺眼
- 👥 **用户管理** — 新建/选择/删除用户档案
- 🔌 **设备连接** — 支持模拟模式与真实蓝牙串口
- 🎯 **五大训练任务** — 每任务 3 套题库，训练时随机抽取
- 🚪 **随时退出** — 训练中可随时点"退出训练"
- 📊 **数据记录** — 自动保存每次训练，统计正确率/趋势/分任务成绩

## 🗂 目录结构

```
ctis_web/
├── backend/
│   ├── app.py            # Flask 后端入口
│   └── task_bank.py      # 五大任务题库
├── static/
│   ├── index.html        # 单页应用入口
│   ├── style.css         # 全局样式
│   └── app.js            # 前端逻辑
├── data/                 # 运行时数据（SQLite）
├── test_api.py           # API 验证脚本
└── requirements.txt
```

## 🚀 启动方法

```bash
# 1. 安装依赖（首次）
pip install -r requirements.txt

# 2. 启动服务
python -m backend.app

# 3. 浏览器打开
http://127.0.0.1:5000
```

## 📝 使用流程

1. **首页**：左侧新建用户（或选择已有用户）
2. **设备连接**：选择"模拟模式" → 点"连接" → 点"运行眨眼校准"
3. **认知训练**：选任务 → 选项自动扫描高亮 → 强眨眼（模拟）确认答案
4. **数据记录**：自动保存，可看历史趋势和按任务统计

## 🔌 真实 TGAM 设备

把"设备连接"切换到 **蓝牙串口** 模式，输入 `COM5`（Windows）或 `/dev/rfcomm0`（Linux）即可。需要后端 `backend/app.py` 中扩展 `serial` 模式的真实解析逻辑（当前默认走模拟信号生成）。

## 🎯 五大任务清单

| 任务 | 题库示例 | 训练目标 |
|---|---|---|
| EEG-Orient 定向力 | 春日/夏日/秋日各 5 题 | 时间/空间/人物定向 |
| EEG-MemEncode 记忆编码 | 水果-颜色/动物-栖息地/物品-材质 | 配对记忆与回忆 |
| EEG-TrailBlink 注意追踪 | 数字 1-5 / 字母 A-E / 颜色序列 | 视觉追踪与顺序记忆 |
| EEG-SemFlow 语义流畅 | 动物/水果/交通工具 | 语义类别识别 |
| EEG-NameBlink 人名再认 | 家庭成员/亲近朋友/照护团队 | 熟人面孔识别 |
